# Marketing Campaign ROI Analysis

## Overview
A Power BI dashboard that analyzes marketing campaign performance, ROI, conversions, and channel effectiveness. The project helps evaluate campaign success and optimize marketing spend.

## Tools Used
- Power BI
- DAX
- Excel
- Microsoft PowerPoint

## Key Features
- Campaign Performance Analysis
- ROI Tracking
- Channel-wise Comparison
- Conversion & Lead Analysis
- Interactive Dashboard

## Key Metrics
- Total Spend
- Revenue Generated
- ROI (%)
- Leads Generated
- Conversions
- CPA (Cost Per Acquisition)

## Outcome
The dashboard provides insights into campaign effectiveness, helping businesses maximize ROI and support data-driven marketing decisions.
